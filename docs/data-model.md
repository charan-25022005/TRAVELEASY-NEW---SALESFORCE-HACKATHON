# TravelEasy — Data Model & Schema Specification

## 1. Custom Objects

### 1.1 `Travel_Request__c` (Travel Request)
Central entity representing a business trip planned by an employee.

| Field Name | Type | Description |
|------------|------|-------------|
| `Employee__c` | Lookup(User) | Requester user record. |
| `Employee_ID__c` | Text(50) | Corporate employee code (e.g., EMP101). |
| `Requester_Role__c` | Picklist | Values: `Employee`, `Manager`. Server-verified. |
| `Destination__c` | Text(255) | Travel destination city/location. |
| `Purpose__c` | Text(255) | Business reason for the trip. |
| `Travel_Start_Date__c` | Date | Start date (cannot be in the past at submission). |
| `Travel_End_Date__c` | Date | Return date (must be >= Start Date). |
| `Estimated_Cost__c` | Currency(18,2) | Pre-trip budget requested. |
| `Status__c` | Picklist | `Draft`, `Submitted`, `Approved`, `Rejected`. |
| `Approver__c` | Lookup(User) | Assigned Manager reviewer. |
| `Approval_Date__c` | DateTime | Timestamp when request was approved. |
| `Rejection_Reason__c` | LongTextArea(1000) | Feedback provided upon rejection. |
| `Notes__c` | LongTextArea(32768) | Additional itinerary or notes. |

### 1.2 `Expense_Report__c` (Expense Report)
Container for expenses incurred for an approved travel request.

| Field Name | Type | Description |
|------------|------|-------------|
| `Travel_Request__c` | Lookup(Travel_Request__c) | Associated approved travel request. |
| `Employee__c` | Lookup(User) | Submitting employee. |
| `Report_Name__c` | Text(255) | Title / description of expense bundle. |
| `Submission_Date__c` | Date | Date submitted. |
| `Total_Amount__c` | Roll-up Summary (SUM) | Sum of `Expense_Item__c.Amount__c`. |
| `Status__c` | Picklist | `Draft`, `Submitted`, `Under Review`, `Approved`, `Rejected`, `Exception Flagged`, `Reimbursed`. |
| `Approver__c` | Lookup(User) | Assigned approver. |
| `Approval_Date__c` | DateTime | Approval timestamp. |
| `Rejection_Reason__c` | LongTextArea(1000) | Rejection explanation. |
| `Has_Blocking_Exceptions__c` | Checkbox | Automatically synchronized by trigger; true if unresolved blocking exceptions exist. |
| `Reimbursement_Status__c` | Picklist | `Not Applicable`, `Pending`, `Processing`, `Completed`, `Failed`. |
| `Reimbursement_Reference__c` | Text(100) | Transaction ID from simulated payment gateway. |
| `Reimbursement_Date__c` | DateTime | Timestamp when payment completed. |

### 1.3 `Expense_Item__c` (Expense Item)
Individual expense entry itemized under an Expense Report. Master-Detail child of `Expense_Report__c`.

| Field Name | Type | Description |
|------------|------|-------------|
| `Expense_Report__c` | Master-Detail(Expense_Report__c) | Parent expense report. |
| `Category__c` | Picklist | `Airfare`, `Hotel & Lodging`, `Ground Transportation`, `Meals & Food`, `Client Entertainment`, `Incidentals & Miscellaneous`. |
| `Transaction_Date__c` | Date | Incurred date. |
| `Vendor__c` | Text(255) | Merchant or service provider. |
| `Amount__c` | Currency(18,2) | Incurred expense amount. |
| `Payment_Method__c` | Picklist | `Corporate Card`, `Personal Card`, `Cash`. |
| `Description__c` | Text(255) | Purpose/item details. |
| `Receipt_Attached__c` | Checkbox | Whether receipt proof has been uploaded. |
| `Receipt_Document_Id__c` | Text(100) | ContentVersion or file reference ID. |
| `Is_Flagged_For_Review__c` | Checkbox | Set to true if Smart Control engine flags an issue. |
| `Flag_Reason__c` | Text(255) | Summary explanation of flagged violation. |

### 1.4 `Expense_Validation_Exception__c` (Expense Exception)
Policy and audit exception generated by the Smart Expense Control Service. Master-Detail child of `Expense_Report__c`.

| Field Name | Type | Description |
|------------|------|-------------|
| `Expense_Report__c` | Master-Detail(Expense_Report__c) | Parent expense report. |
| `Expense_Item__c` | Lookup(Expense_Item__c) | Specific item triggering exception (optional for budget overrun). |
| `Exception_Type__c` | Picklist | `Policy Violation`, `Missing Receipt`, `Potential Duplicate`, `Budget Overrun`. |
| `Severity__c` | Picklist | `Low`, `Medium`, `High`, `Critical`. |
| `Details__c` | LongTextArea(32768) | Context, amounts, policy thresholds compared. |
| `Status__c` | Picklist | `Open`, `Under Review`, `Approved`, `Waived`, `Rejected`, `Resolved`. |
| `Reviewer__c` | Lookup(User) | Manager or Finance reviewer resolving exception. |
| `Resolution_Comments__c` | LongTextArea(1000) | Reviewer notes upon resolution. |
| `Resolved_Date__c` | DateTime | Timestamp when status moved to resolved/waived. |
| `Is_Blocking__c` | Formula / Checkbox | True if Severity is High or Critical and Status is Open/Under Review. |

### 1.5 `Integration_Log__c` (Integration Log)
Audit log for REST API calls and asynchronous payment transactions.

| Field Name | Type | Description |
|------------|------|-------------|
| `Endpoint__c` | Text(255) | Target URL or resource mapping. |
| `Operation__c` | Text(100) | Name of service operation. |
| `Reference_Id__c` | Text(100) | Unique idempotency or correlation key. |
| `Related_Record_Id__c` | Text(50) | Id of affected Salesforce record. |
| `Status__c` | Picklist | `Success`, `Failed`, `Retried`. |
| `Request_Payload__c` | LongTextArea(32768) | Sanitized request payload. |
| `Response_Payload__c` | LongTextArea(32768) | Sanitized response payload. |
| `Error_Message__c` | LongTextArea(32768) | Detailed error message and stack trace. |
| `Execution_Time_Ms__c` | Number(18,0) | Callout or transaction duration in ms. |

## 2. Custom Metadata Type: `Travel_Expense_Policy__mdt`

Controls role-based allowances and rules for all 6 expense categories.

| Field Name | Type | Description |
|------------|------|-------------|
| `Role__c` | Text(50) | `Employee` or `Manager`. |
| `Category__c` | Text(100) | Expense category matching `Expense_Item__c.Category__c`. |
| `Single_Transaction_Limit__c` | Currency(18,2) | Maximum allowed per transaction without exception. |
| `Daily_Limit__c` | Currency(18,2) | Maximum aggregate allowed per day for category. |
| `Receipt_Required_Threshold__c` | Currency(18,2) | Receipts required if amount >= this value. |
| `Allowed_Payment_Methods__c` | Text(255) | Comma-separated allowed payment methods. |
| `Requires_Manager_Review__c` | Checkbox | Flags if category mandates specific manual review. |
| `Is_Active__c` | Checkbox | Enables or disables the policy rule. |
